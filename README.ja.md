# Ben Plaud Sync 0.1.4

ObsidianデスクトップへPLAUDの文字起こし・要約を手動で取り込む非公式プレビューです。PLAUD/Obsidianの公式製品ではありません。[English / 詳細](README.md)

## 導入

1. Vaultをバックアップし、別のテストVaultで確認してください。他のPLAUD同期プラグインは独立した動作を避けるため無効化します。
2. `main.js`、`manifest.json`、ライセンスを `<Vault>/.obsidian/plugins/ben-plaud-sync/` にコピーし、コミュニティプラグインで有効化します。公式マーケットプレイスには掲載されていません。
3. アカウントに合う完全一致API originを選びます：`https://api.plaud.ai`（既定）または `https://api-apne1.plaud.ai`。Legacy v3が既定、v4は実験的でworkspace IDが必要です。
4. 正規の権限のあるPLAUD利用手順で自分が取得したトークンをSession tokenへ入力し、欄からフォーカスを外します。本プラグインにログイン・認証情報取得機能はありません。ブラウザ認証情報の抽出手順も提供しません。トークン、ヘッダー、署名URL、HARをチャットやIssueに送らないでください。
5. `Sync now`を押し、認識できるPLAUD保存先の正確なホストだけ承認してください。保存先にAPIトークンは送りません。結果の全件数を確認し、未完了や失敗を全件成功と扱わないでください。
6. 終了時は`Forget`でトークン参照とホスト許可を消去します。再起動・更新・無効化でも消えます。JavaScriptのメモリ完全消去は保証できません。

## 保存と制限

ノートはVault直下の`Plaud`に固定。名前は「Title - YYYY-MM-DD HHmm」、録音時刻を常にJSTへ変換します。取込時刻は使わず、欠落時は日時不明の表示です。同じ内容は重複せず、変更は別のスナップショットへ保存。衝突時は短い安定IDを付け、既存ノートを上書きしません。旧ハッシュ名の自プラグインノートは本文を変えず改名できます。編集済み内容は保持して競合を報告します。

手動同期のみ。起動時同期、バックグラウンド同期、テレメトリ、音声取得、PLAUD側の変更はありません。トークンはセッションメモリだけで、設定やログには保存しません。安全診断のコピーは、ユーザーがボタンを押した時だけ、型・件数などの限定情報をコピーします。

1要求20秒、入力4MiB、gzip展開後4MiB、1同期10分・2000録音まで。厳密なTLS、公開IPv4へのDNS固定、リダイレクト拒否、限定MIMEを使用。API JSON圧縮や任意アーカイブ、IPv6のみの環境などは未対応です。

固定フォルダ検査はOSサンドボックスではなく、Obsidianや他プラグインの権限を取り消しません。ノートは平文です。別プロセスの同時変更やマルウェアへの隔離を保証しません。70件の合成データ試験に成功し、1つのローカル環境でLegacy v3取込と改名を確認しましたが、全アカウント・地域・バージョン・v4での互換性は未検証です。非公式APIは変わる可能性があります。

ビルド：`npm run check`。パッケージ：`python3 scripts/package.py`。Node 18以降、npm依存パッケージ不要。MIT、Leonard Sellem版1.0.1とckelsoe版0.43.0への帰属・原ライセンスは英語READMEと同梱ライセンスに記載。
